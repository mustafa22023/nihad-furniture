# نهاد عفنان الظفيري – مفروشات وأثاث

Simple, responsive, single‑page website for a Saudi furniture & decor store.  
Features:

- Arabic & English language toggle (i18n)
- Dark/Light theme switch
- Main hero carousel
- Dynamic product grid with tabs and modal detail view
- Offers carousel
- Services, delivery info, contact section
- Floating WhatsApp button

# Clone and open index.html in any browser
